# Security policy

## Reporting a vulnerability
Please **do not** open a public issue. Report it privately via
[GitHub private vulnerability reporting](https://github.com/Charlesuru/RefProj/security/advisories/new).
You will get an answer within a few working days.

## Scope
This is a public reference project. It contains no secrets: signing keys, certificates, store credentials and
Firebase configuration live outside the repository (see [docs/secrets.md](docs/secrets.md)). If you find something
that looks like a secret in the code or history, please report it the same way.
